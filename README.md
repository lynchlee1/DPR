# 사진 정리

선택한 폴더와 모든 하위 사진 폴더를 재귀적으로 탐색해 촬영 시간순으로 정렬하고, 1분 안에 촬영된 바로 이웃한 사진의 시각적 유사도를 비교하는 로컬 앱입니다. 기준을 넘은 사진을 추천 후보로 계산하지만, 처음에는 아무 사진도 선택하지 않습니다. 실제 파일은 사용자가 후보를 선택하고 확인하기 전까지 이동하지 않습니다.

## 실행

macOS Finder에서 `run.command`를 더블 클릭하거나 터미널에서 다음을 실행합니다.

```bash
./run.command
```

첫 실행에는 Python과 프런트엔드 의존성 설치로 시간이 조금 더 걸립니다. 이후 브라우저에서 `http://127.0.0.1:8765`가 자동으로 열립니다.

## 프로젝트 구조

```text
src/photo_sorter/  Python 백엔드와 이미지 분석
frontend/src/      React 사용자 인터페이스
tests/             백엔드 단위 테스트
run.command        macOS 실행 진입점
```

## 사용 흐름

1. `폴더 선택`으로 사진 폴더 또는 여러 사진 폴더를 담은 상위 폴더를 고릅니다. 하위 폴더는 자동으로 모두 포함됩니다.
2. 유사도 기준을 조절합니다. 기본값은 88%입니다.
3. `일반 분석` 또는 `빠른 분석`을 선택하고 분석을 시작합니다.
4. 왼쪽에서 그룹을 고른 뒤 가운데의 수평 카드 열에서 모든 사진을 검토합니다. 사진이 많으면 카드 열을 좌우로 스크롤할 수 있습니다.
5. 후보 건수가 표시된 최종 삭제 버튼을 누르고 확인하면 선택한 사진만 시스템 휴지통으로 이동합니다.

빠른 분석은 기본 96%인 유사도 기준을 사용자가 조절할 수 있습니다. 각 그룹에서 마지막에 촬영된 사진 1장을 보존한 채 나머지를 삭제 후보로 미리 지정합니다. 좌우 방향키로 그룹을 이동하며 보존 사진과 삭제 후보를 확인하거나 직접 수정할 수 있고, `여기까지 정리하기`를 누르면 현재 그룹까지 검토한 후보만 휴지통으로 이동합니다. 뒤쪽의 미검토 그룹은 그대로 남습니다. 빠른 분석도 확인 없이 파일을 이동하지 않습니다.

그룹 안의 모든 사진을 위로 밀면 보관(`SAVE`), 아래로 밀면 삭제 후보(`DELETE`)가 됩니다. 스와이프하는 동안 사진이 원래 있던 자리가 초록색 또는 빨간색으로 바뀌므로 놓기 전에 결정을 확인할 수 있습니다.

키보드의 왼쪽/오른쪽 화살표로 그룹을 이동할 수 있습니다. 숫자키 `1`-`9`를 누르면 현재 그룹에서 해당 순서의 사진 1장만 보존하고 나머지는 삭제 후보로 표시합니다. `Shift+S`는 현재 선택한 사진을 보관하고, `Shift+D`는 현재 사진을 삭제 후보로 추가합니다. `Shift+N`은 현재 그룹을 전부 보관하고, `Shift+A`는 현재 그룹을 전부 삭제 후보로 표시합니다. 일반 `S`, `D`, `A`, `N`은 사진 상태를 바꾸지 않습니다.

`Cmd`, `Control`, `Option` 조합은 브라우저에 양보합니다. 예를 들어 `Cmd+D`는 Chrome의 북마크 명령만 실행하며 사진을 후보로 추가하지 않습니다.

## 정렬과 비교 방식

- 시간: EXIF 촬영 시간, 파일명의 시간, 파일 수정 시간 순서로 사용합니다.
- 폴더: 선택한 폴더 아래의 모든 하위 폴더를 재귀적으로 탐색합니다. 서로 다른 하위 폴더의 사진도 하나의 시간순 목록에서 비교하며, 화면에는 선택한 폴더 기준의 상대 경로가 표시됩니다.
- 비교 범위: 시간순으로 바로 이웃한 사진 중 시간 차이가 60초 이하인 쌍만 비교합니다.
- 지문: pHash, dHash, aHash, 색상 히스토그램을 조합해 0-100점 유사도를 계산합니다.
- 그룹: 60초 이내인 사진 중 유사도 기준을 통과한 쌍만 연결해 그룹으로 묶습니다. 같은 시간대라도 시각적 연결이 없는 사진은 같은 그룹에 포함하지 않습니다.
- 초기 상태: 분석 결과가 열려도 삭제 후보는 0장입니다. 그룹 안의 모든 사진은 동등하게 보관 또는 후보로 판정할 수 있습니다.

지원 확장자는 JPEG, PNG, WebP, TIFF, BMP입니다. 읽을 수 없는 파일은 전체 스캔을 중단하지 않고 결과에 오류로 기록합니다.

## 안전 원칙

- 사진은 외부로 업로드되지 않습니다.
- `전부 후보`를 사용하면 한 그룹의 모든 사진을 선택할 수 있으며, 최종 확인 창에서 사진이 한 장도 남지 않는 그룹 수를 다시 경고합니다.
- 스와이프, 단축키, `후보 추가` 버튼은 후보 상태만 바꿉니다. 파일 이동은 후보 건수가 표시된 최종 삭제 버튼과 확인 창을 거쳐야만 실행됩니다.
- 선택한 폴더 밖의 파일은 이동할 수 없습니다.
- 영구 삭제 대신 운영체제의 휴지통을 사용합니다.
- 제공된 실제 샘플 폴더는 읽기 전용으로 스캔했으며 원본 파일을 이동하지 않았습니다.

## 검증

```bash
pytest -q
cd frontend && npm run build
```

테스트는 EXIF와 파일명 시간 우선순위, 중첩 폴더 재귀 탐색, 1분 범위, 인접 쌍만 비교하는 규칙, 시각적으로 무관한 시간 이웃의 그룹 제외, 유사도 판별, 중첩 사진의 휴지통 이동, 전체 그룹 삭제 확인, 폴더 밖 경로 차단을 다룹니다.
