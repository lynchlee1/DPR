# 사진 정리

선택한 폴더의 사진을 촬영 시간순으로 정렬하고, 1분 안에 촬영된 바로 이웃한 사진의 시각적 유사도를 비교하는 로컬 앱입니다. 하위 사진 폴더를 함께 탐색할지와 사진이 있는 촬영일 중 몇 일을 분석할지 선택할 수 있습니다. 기준을 넘은 사진을 추천 후보로 계산하지만, 처음에는 아무 사진도 선택하지 않습니다. 실제 파일은 사용자가 후보를 선택하고 확인하기 전까지 이동하지 않습니다.

## 실행

Python이나 Node.js를 미리 설치할 필요가 없습니다. 첫 실행에 필요한 도구를 프로젝트 내부에 자동으로 내려받으므로 인터넷 연결만 필요합니다.

macOS Finder에서 `run.command`를 더블 클릭하거나 터미널에서 다음을 실행합니다.

```bash
./run.command
```

Windows에서는 PowerShell에서 다음을 실행합니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\run.ps1
```

첫 실행에는 Python과 프런트엔드 의존성 설치로 시간이 조금 더 걸립니다. 이후 브라우저에서 `http://127.0.0.1:8765`가 자동으로 열립니다.

빌드하는 컴퓨터에도 Python이나 Node.js를 미리 설치할 필요가 없습니다. 자세한 방법은 [Windows·macOS 빌드 안내](docs/build.md)를 참고하세요. 버전 태그를 푸시하면 GitHub Releases에 macOS와 Windows용 ZIP이 자동으로 등록됩니다. 최종 사용자는 프로젝트 코드를 받지 않고 운영체제에 맞는 ZIP만 내려받으면 되며, 배포본은 Python 런타임을 포함하므로 인터넷 연결 없이 실행됩니다.

## 프로젝트 구조

```text
src/photo_sorter/  Python 백엔드와 이미지 분석
frontend/src/      React 사용자 인터페이스

scripts/           운영체제별 배포 빌드 스크립트
```

## 사용 흐름

1. `폴더 선택`으로 사진 폴더 또는 여러 사진 폴더를 담은 상위 폴더를 고르고, `보관 저장 위치`에서 분류를 마친 사진을 옮길 루트 폴더를 선택합니다.
2. 필요하면 왼쪽의 `세부 설정`을 엽니다. `하위 폴더 탐색`의 O는 모든 하위 폴더를 포함하고 X는 선택한 폴더의 사진만 포함합니다. `JSON 파일 청소`가 O이면 분석 시작 시 같은 탐색 범위의 JSON 파일을 삭제하며, `방향키 연속 이동 속도`에서 키를 누르고 있을 때의 그룹 이동 간격을 조절할 수 있습니다.
3. `분석 날짜 수`를 비워 두면 모든 날짜를 분석합니다. N을 입력하면 사진이 있는 서로 다른 촬영일을 오래된 날부터 또는 최신 날부터 정렬해 첫 N일의 사진만 분석합니다. 날짜 선정이 끝나면 실제 시작일과 종료일을 진행 화면과 설정 영역에 표시합니다.
4. 유사도 기준을 조절합니다. 기본값은 88%입니다.
5. `일반 분석` 또는 `빠른 분석`을 선택하고 분석을 시작합니다.
6. 왼쪽에서 유사 사진 그룹 또는 단독 사진을 고른 뒤 가운데에서 검토합니다. 세부 설정의 `단독 사진 표시`를 X로 바꾸면 재분석 없이 1장짜리 그룹을 즉시 숨길 수 있고, O로 바꾸면 다시 표시됩니다. 숨김은 검토 화면에만 적용되며, 보관 상태인 단독 사진은 보관 이동 대상에 계속 포함됩니다. 유사 사진이 많으면 카드 열을 좌우로 스크롤할 수 있습니다.
7. `보관 N장 이동`을 확인하면 보관 상태 사진과 영상이 저장 루트 아래 `Photos/YYYYMMDD`로 이동합니다. 삭제 후보는 기존 최종 삭제 버튼을 확인한 뒤 시스템 휴지통으로 이동합니다.

상단의 `계산값 초기화`는 현재 분석 결과와 검토 상태, 이미지 특징 및 미리보기 캐시를 비워 메모리를 정리합니다. 실행 전 확인을 거치며 원본 사진과 폴더 설정은 삭제하지 않습니다. 분석 중에는 사용할 수 없습니다.

빠른 분석은 기본 96%인 유사도 기준을 사용자가 조절할 수 있습니다. 각 그룹에서 마지막에 촬영된 사진 1장을 보존한 채 나머지를 삭제 후보로 미리 지정합니다. 좌우 방향키로 그룹을 이동하며 보존 사진과 삭제 후보를 확인하거나 직접 수정할 수 있고, `여기까지 정리하기`를 누르면 현재 그룹까지 검토한 후보만 휴지통으로 이동합니다. 뒤쪽의 미검토 그룹은 그대로 남습니다. 빠른 분석도 확인 없이 파일을 이동하지 않습니다.

그룹 안의 모든 사진을 위로 밀면 보관(`SAVE`), 아래로 밀면 삭제 후보(`DELETE`)가 됩니다. 스와이프하는 동안 사진이 원래 있던 자리가 초록색 또는 빨간색으로 바뀌므로 놓기 전에 결정을 확인할 수 있습니다.

키보드의 왼쪽/오른쪽 화살표로 그룹을 이동할 수 있습니다. 숫자키 `1`-`9`를 누르면 현재 그룹에서 해당 순서의 사진 1장만 보존하고 나머지는 삭제 후보로 표시합니다. `Shift+S`는 현재 선택한 사진을 보관하고, `Shift+D`는 현재 사진을 삭제 후보로 추가합니다. `Shift+N`은 현재 그룹을 전부 보관하고, `Shift+A`는 현재 그룹을 전부 삭제 후보로 표시합니다. 일반 `S`, `D`, `A`, `N`은 사진 상태를 바꾸지 않습니다.

`Cmd`, `Control`, `Option` 조합은 브라우저에 양보합니다. 예를 들어 `Cmd+D`는 Chrome의 북마크 명령만 실행하며 사진을 후보로 추가하지 않습니다.

## 정렬과 비교 방식

- 시간: EXIF 촬영 시간, 파일명의 시간, 파일 수정 시간 순서로 사용합니다.
- 날짜 제한: 제한을 설정하면 전체 사진에서 EXIF 촬영 시각, 파일명 시각, 파일 수정 시각 순으로 날짜를 확인합니다. 선택한 방향에서 첫 N개의 서로 다른 촬영일에 속한 사진만 지문과 유사도를 분석하며, 사진이 없는 달력 날짜는 N일에 포함하지 않습니다. 결과에는 선정된 촬영일의 시작일, 종료일, 일수와 분석 사진 수가 함께 표시됩니다.
- 폴더: `하위 폴더 탐색`이 O이면 모든 하위 폴더를 재귀적으로 탐색하고, X이면 선택한 폴더의 직속 사진만 탐색합니다. O일 때는 서로 다른 하위 폴더의 사진도 하나의 시간순 목록에서 비교하며, 화면에는 선택한 폴더 기준의 상대 경로가 표시됩니다.
- 비교 범위: 시간순으로 바로 이웃한 사진 중 시간 차이가 60초 이하인 쌍만 비교합니다.
- 지문: pHash, dHash, aHash, 색상 히스토그램을 조합해 0-100점 유사도를 계산합니다.
- 그룹: 60초 이내인 사진 중 유사도 기준을 통과한 쌍만 연결해 그룹으로 묶습니다. 어떤 유사 그룹에도 속하지 않은 사진은 이동할 수 있도록 1장짜리 단독 사진 그룹으로 표시합니다.
- 영상: 영상은 유사도나 중복 검사를 하지 않고 미리보기에서도 숨깁니다. 보관 수량에는 자동으로 포함하며, 파일명 시각을 먼저 사용하고 없으면 파일 수정 시각으로 날짜를 정합니다.
- 초기 상태: 분석 결과가 열려도 삭제 후보는 0장입니다. 그룹 안의 모든 사진은 동등하게 보관 또는 후보로 판정할 수 있습니다.
- 보관 이동: 사용자가 확정하면 보관 상태 사진을 복사하지 않고 선택한 저장 루트의 `Photos/YYYYMMDD`로 이동합니다. `YYYYMMDD`는 분석에서 결정한 촬영 날짜입니다. 같은 파일명의 기존 파일과 SHA-256 해시가 같으면 덮어쓰고, 다르면 `(1)`, `(2)`를 붙여 기존 파일을 보존합니다.

지원 사진 확장자는 JPEG, PNG, WebP, TIFF, BMP이며, 영상 확장자는 3GP, AVI, M4V, MKV, MOV, MP4, MPEG, MPG, WebM입니다. 읽을 수 없는 파일은 전체 스캔을 중단하지 않고 결과에 오류로 기록합니다.

## 안전 원칙

- 사진은 외부로 업로드되지 않습니다.
- 보관 사진 이동은 별도 확인 전에는 실행되지 않으며, 이동에 성공한 사진만 현재 검토 목록에서 제거됩니다. 저장 폴더를 만들거나 쓸 수 없으면 이동 전에 중단하고, 개별 실패가 있으면 원본·목적지·운영체제 오류를 화면에 표시합니다.
- `전부 후보`를 사용하면 한 그룹의 모든 사진을 선택할 수 있으며, 최종 확인 창에서 사진이 한 장도 남지 않는 그룹 수를 다시 경고합니다.
- 스와이프, 단축키, `후보 추가` 버튼은 후보 상태만 바꿉니다. 파일 이동은 후보 건수가 표시된 최종 삭제 버튼과 확인 창을 거쳐야만 실행됩니다.
- 선택한 폴더 밖의 파일은 이동할 수 없습니다.
- 사진과 영상 정리는 영구 삭제 대신 운영체제의 휴지통을 사용합니다. 단, 사용자가 `JSON 파일 청소`를 O로 켠 경우 JSON 파일은 분석 시작 시 영구 삭제됩니다.
- 제공된 실제 샘플 폴더는 읽기 전용으로 스캔했으며 원본 파일을 이동하지 않았습니다.

## 검증

```bash
pytest -q
cd frontend && npm run build
```

테스트는 EXIF와 파일명 시간 우선순위, 중첩 폴더 재귀 탐색, 오래된/최신 촬영일 N일 제한과 선택 날짜만의 지문 분석, 계산값 초기화, 촬영일별 보관 이동과 파일명 충돌 방지, 1분 범위, 인접 쌍만 비교하는 규칙, 시각적으로 무관한 시간 이웃의 그룹 제외, 유사도 판별, 중첩 사진의 휴지통 이동, 전체 그룹 삭제 확인, 폴더 밖 경로 차단을 다룹니다.
